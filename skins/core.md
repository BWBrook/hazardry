# Core (no skin)
### Play sheet for the Hazardry core rules with the default names

This is not a skin. It lets the harness run the core game as the Adventurer's Manual allows: "Pick a skin, or play the core with the default names" (Manual 2.4). It adds no rules. The Adventurer's Manual and the Custodian's Almanac govern everything, and this sheet only collects what a skin would otherwise supply. It is marked `play_only` in the manifest and is left out of the published books.

---

## Adventurer-facing summary

### Attributes (default names, Manual 2.1.1)

| Key | Name | Covers |
|--|---|---|
| MGT | Might | strength, endurance, force, brutality |
| REF | Reflex | speed, coordination, balance, stealth, aim |
| INT | Intellect | knowledge, planning, perception, systems |
| EMP | Empathy | social sense, willpower, leadership, composure |
| LCK | Luck | your token pool, and the target when sheer chance decides |

**Rules reminder:** a natural 1 always succeeds and a natural 20 always fails, whatever the target; neither can be nudged.

Luck tokens, Stamina, gear, tags and milestones work exactly as in the Manual. The party's shared fuse is simply called **Pressure**.

### Optional modules

The core has no skin procedures of its own. A campaign may switch on any of the Almanac's optional modules (Almanac 7 and Toolkit Part II), for example:
- **Condition Tracks:** Fear, Radiation and Madness are extra 0–5 fuses like Pressure, but each is tied to one specific hazard and tracked per character;
- **Wealth & Attention:** a 0–4 money track (Toolkit, Part II H).

The campaign's setup says which are on.

## Custodian-facing summary

### Pressure (Almanac 4)

| Step | Mood | Custodian levers |
|--|---|---|
| 0 | Calm | None yet |
| 1 | Unease | Cosmetic omens |
| 2 | Stirrings | Minor Disadvantage, flicker tech |
| 3 | Rumble | Noticeable penalty, NPC mistrust |
| 4 | Fracture | Special abilities cost +1 Luck token; environment turns hostile |
| 5 **Crisis** | Backlash | Trigger crisis, then reset Pressure to **0** |

Earning, purging and running the fuse follow Almanac 4 as written. The core prints no crisis table; make each crisis a dramatic twist with real consequences, as Almanac 4 directs.
